    The test

    A fake "new bank account, pay today" email. A good check calls the supplier's real number before paying.

    The big idea

    A rulebook advises. It guides the AI. The AI can ignore it.
    Code enforces. Locks hold no matter what.

    • Approve stays locked until someone calls the supplier's real number
      • 
          
    • A call to the number the requester gave doesn't count
      • 
          
    • If the bank details change after approval, the approval is cancelled
      • 
          
    • Whoever prepared a payment can't approve it
      • 
          
    • If the checker is away, it goes to the backup, or waits
      • 
          
    • Approving without opening the evidence is blocked

    What this does not prove
    
    
    
      
    
        
    Limits we accept
    
        
      
          
    • A rulebook is not a lock. Only code controls what the AI can do.
      • 
          
    • Answers vary from run to run.
      • 
          
    • 11 cases is small. A direction, not proof.
      • 
          
    • The rules are made up. Real companies set their own.
      • 
          
    • Briefing scores are rough keyword checks.
      • 
          
    • Code checks process, not truth. A fooled checker can still approve.
